# Lavanya Ravichandran — Portfolio

[View the live portfolio](https://laravich.github.io/)

I am a wireless R&D engineer based in Nuremberg, Germany. My work combines 5G/6G communications research, network simulation, software-defined radio and networking, and data analysis. This portfolio brings together my experience, selected projects, publications, and contact information.

## Background

- **Fraunhofer IIS (2021–2025):** 5G/6G sidelink, vehicular network simulation, mmWave and sub-THz channel studies, and energy-saving research.
- **TU Ilmenau:** M.Sc. in Communications and Signal Processing, with a thesis on radio resource selection for aperiodic 5G NR V2X traffic.
- **IMMS GmbH:** Work on time-sensitive networking with LS1021A-TSN boards and Linux scripting.
- **Tata Consultancy Services:** Cisco ACI automation, testing, and network debugging.
- **Current development:** Independent satellite and data projects alongside a Data Science & AI program.

My tools include Python, MATLAB, C/C++, OMNeT++, Simu5G, INET, Veins, SUMO, QuaDRiGa, GNU Radio, USRP, Wireshark, Pandas, Plotly, and Streamlit.

## About this website

The portfolio is a static website in `index.html`, hosted with GitHub Pages. The preview image is `portfolio-preview.png`; no build step or framework is required.

To preview a local clone, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`. Updates to the default branch are published through the repository's GitHub Pages settings.
